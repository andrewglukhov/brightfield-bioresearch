# Brightfield Bioresearch — сайт

Статический сайт без сборки: HTML + CSS + JS. Три языка (RU / KZ / EN), адаптивная вёрстка.

## Структура

```
index.html      главная страница
privacy.html    политика конфиденциальности
favicon.svg     иконка
css/style.css   стили (цвета — переменные в :root)
js/i18n.js      ВСЕ тексты на трёх языках
js/main.js      логика: языки, рендер контента, счётчики, форма
```

## Что заполнить перед публикацией

1. **Email** — `js/main.js`, поле `CONFIG.contactEmail` (сейчас `info@brightfieldbio.kz`).
2. **Форма заявки** — `CONFIG.formEndpoint` в `js/main.js`.
   Пока пусто, форма открывает почтовый клиент с готовым письмом (mailto).
   Чтобы письма приходили без почтового клиента, зарегистрируйте бесплатный
   endpoint на [Formspree](https://formspree.io) или [Getform](https://getform.io)
   и вставьте URL вида `https://formspree.io/f/xxxxxxxx`.
3. **Город и часы работы** — ключи `contact.location` и `contact.hours` в `js/i18n.js`.
4. **Цифры в счётчиках** — `data-count` в `index.html` (блок `.stats`) и подписи `stats.*` в `js/i18n.js`.
5. **Команда** — раздел `team.roles` в `js/i18n.js`. Сейчас указаны роли без имён;
   имена и фото можно добавить туда же.
6. **Утверждения о качестве** (GLP, ICH, SOP, сроки «от 4 недель») — проверьте, что они соответствуют реальным процессам, либо отредактируйте `why.*` в `js/i18n.js`.

## Как добавить или изменить текст

Все строки лежат в `js/i18n.js` в трёх словарях: `ru`, `kk`, `en`.
Меняйте текст сразу в трёх местах, чтобы языки не расходились.

## Размещение на хостинге

Загрузите содержимое папки в корень сайта (public_html, www и т.п.).
Сборка и сервер не нужны. Работает на любом статическом хостинге:
обычный shared-хостинг, GitHub Pages, Netlify, Vercel, Cloudflare Pages.

Язык по умолчанию — казахский (`CONFIG.defaultLang` в `js/main.js`). Выбор посетителя запоминается в браузере. Язык можно принудительно задать через параметр: `?lang=kk`, `?lang=en`, `?lang=ru`.
